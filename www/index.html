Relay laman

Cloudflare percuma

Sesetengah laman (titik biru) tidak membenarkan dirinya dipaparkan di dalam app lain. Relay percuma anda di Cloudflare membuang sekatan itu, supaya laman tersebut keluar di dalam app, di mana-mana, tanpa PC. Tanpa relay, laman itu dibuka dalam pelayar di atas app.

Relay juga membuang iklan dari laman yang dibuka melaluinya. infobanjir Terengganu & met.gov.my hanya menerima sambungan dari Malaysia, jadi kedua-duanya tetap diganti dengan kad di Dashboard atau dibuka di tab baru.

  1. Daftar akaun percuma di dash.cloudflare.com (emel + kata laluan).
  2. Workers & Pages → Create → Hello World → beri nama (cth cuaca-relay) → Deploy.
  3. Taip Kunci relay anda sendiri di bawah (cth Kunci-Saya-2026) → Simpan.
  4. Tekan Salin skrip relay di bawah → dalam Cloudflare: Edit code → padam semua → tampal → Deploy.
  5. Salin alamat worker (https://cuaca-relay.….workers.dev) ke Alamat relay → Simpan → Uji relay.
